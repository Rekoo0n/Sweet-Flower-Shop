# 🌸 Our Blooms® — Sweet Flower Shop

> Адаптивная верстка лендинга цветочной студии и магазина флористики по макету из Figma. Проект разработан для демонстрации чистой семантической верстки, архитектуры CSS по методологии БЭМ и интерактивных компонентов на чистом JavaScript без сторонних библиотек.

## 🛠 Стек технологий

* **HTML5:** Семантическая разметка (`nav`, `header`, `main`, `section`, `article`, `aside`, `footer`), WAI-ARIA атрибуты доступности (`aria-expanded`, `aria-label`, `aria-live`, `role="region"`), ленивая загрузка изображений (`loading="lazy"`).
* **CSS3:** Методология **БЭМ (BEM)**, **Flexbox**, дизайн-токены через **CSS Custom Properties** (`:root`), кастомная ключевая анимация (`@keyframes badgeSpin`), поддержка доступности `@media (prefers-reduced-motion: reduce)`.
* **JavaScript (ES6+):** Чистый **Vanilla JS** (без внешних зависимостей и плагинов).
* **Шрифты:** Google Fonts (`Caprasimo` и `Outfit`).

## ✨ Реализованный функционал и особенности

1. **Полная адаптивность (Responsive Design):** Корректное отображение на всех экранах от `1200px+` (Desktop) с плавными переходами на `900px` (Tablet), `600px`, `400px` и вплоть до `320px` (Mobile) без горизонтального скролла.
2. **Интерактивная карусель галереи (`#gallery`):**
   * Переключение слайдов кнопками Вперед/Назад и динамически генерируемыми точками-индикаторами.
   * Поддержка перетаскивания мышью (**Drag-to-scroll**) на десктопе и свайпов (**Touch swipe**) на смартфонах.
   * Управление стрелками клавиатуры (`ArrowLeft` / `ArrowRight`) в фокусе и автопрокрутка с паузой при наведении курсора.
   * Автоматический пересчет позиции при изменении размера окна через `ResizeObserver`.
3. **Умная навигация и мобильное меню:**
   * Фиксированная шапка с появлением тени при прокрутке (`requestAnimationFrame`).
   * Адаптивное бургер-меню с анимацией иконки, закрытием по клику вне меню, нажатию клавиши `Escape` или выбору пункта.
   * **Scroll-Spy** на базе `IntersectionObserver` для автоматической подсветки активного раздела в навигации и плавный скролл с учетом высоты фиксированной шапки.
4. **Анимации при скролле (Scroll-Reveal):** Плавное каскадное появление текстовых блоков, карточек услуг и баннеров при прокрутке страницы через `IntersectionObserver`.
5. **Микро-интерактив (Toast-уведомления):** Доступные всплывающие уведомления (`aria-live="polite"`) при загрузке страницы и взаимодействии с CTA-кнопками.
